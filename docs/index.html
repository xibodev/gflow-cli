CLI Command Reference

Rich, composable subcommands designed for scripts, pipelines, and interactive terminals.

Usage: gflow image <prompt> [flags]

Generates high-resolution images via Gemini Imagen 3 (default, extension-free) or Google Flow. Never overwrites existing files.

-P, --provider: gemini (default, extension-free), flow
-a, --aspect: landscape, square, portrait, 4:3, 3:4
-o, --output: Output file path or directory (default: ./output)
--json: Output machine-readable JSON array of assets
Usage: gflow video <prompt> [flags]

Generates cinematic videos via Gemini Veo (default), MiniMax H3, or Google Flow.

-P, --provider: gemini (default), minimax, flow
-d, --duration: 4, 5, 6, 8, or 10 seconds
-r, --resolution: 720p, 768P, 1080p, 2K, 4k
-o, --output: Output video file path or directory
Usage: gflow audio <prompt>

Generates audio and music tracks via Gemini's Lyria / MusicFX pipeline.

Example: gflow audio "upbeat acoustic guitar with warm drums"
Usage: gflow chat <prompt>

Instant terminal chat with Gemini Flash. Works extension-free and prints clean answers directly to stdout.

Usage: gflow status [flags]

Inspects the health and authentication readiness of Gemini, MiniMax, and Google Flow backends.

Usage: gflow browser

Launches an extension-free Chrome instance for Google Flow with CDP remote debugging enabled on port 9222.
