CLI Command Reference

Rich, composable subcommands designed for scripts, pipelines, and interactive terminals.

Usage: gflow image <prompt> [flags]

Generates high-resolution images via Imagen 4 (Nano Banana 2). Never overwrites existing generations.

-a, --aspect: landscape (16:9), square (1:1), portrait (9:16), 4:3, 3:4
-c, --count: Number of image variations (1–4)
-m, --model: narwhal (default), harbor_seal (lite), gem_pix_2 (pro)
-o, --output: Output file path or directory (default: ./output)
--ref: Reference image path or remote media ID
--json: Output machine-readable JSON array of assets
Usage: gflow video <prompt> [flags]

Generates cinematic videos via Veo 3.1 with async background polling.

-d, --duration: 4, 6, 8, or 10 seconds (default: 10)
-r, --resolution: 720p (native), 1080p, 4k (upsampled pass)
--start: Start frame image path or media ID
--end: End frame image path or media ID (smooth interpolation)
Usage: gflow upsample <media_id> [flags]

Runs Google Flow's secondary upsampler pass over an existing 720p video clip.

-r, --resolution: 1080p (free pass) or 4k
-o, --output: Output file path for upsampled clip
Usage: gflow history [flags]

Inspects your local generation registry saved in ~/.gflow/history.json.

-l, --limit: Number of recent generations to show (default: 20)
--json: Output history as structured JSON
Usage: gflow setup

One-time setup command. Extracts the embedded Chrome extension to ~/.gflow/extension and launches Google Flow in your browser.

REST API Drop-In

OpenAI-Compatible HTTP Server

Start the background bridge server with gflow serve --port 8001. Existing tools that talk to /v1/images/generations work without modification. 

curl http://127.0.0.1:8001/v1/images/generations \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "futuristic neon Tokyo street",
    "n": 1,
    "size": "1024x1024"
  }'
