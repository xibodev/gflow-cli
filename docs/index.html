Architecture

The Problem with Browser Extensions

Typical Scraping / Extension Architecture Fragile

Relies on unpacked extensions in Chrome developer mode, continuous WebSocket daemon processes on localhost, and persistent bridge listeners that fail silently whenever browser tabs close or session cookies expire.

User ➔ CLI ➔ Localhost Daemon:8001
  ➔ WebSocket ➔ Chrome MV3 Extension
  ➔ Tab Context ➔ Cloudflare / Bot Gate ➔ Failure
gflow Unified Engine Clean & Direct

Pure Go HTTPS. For Gemini and MiniMax, gflow reads local desktop session tokens and speaks directly to cloud endpoints over HTTPS. For Flow, it connects directly to an open tab via Chrome DevTools Protocol (CDP) with zero extensions.

User ➔ CLI ➔ Pure Go HTTPS Client
  ➔ Direct Cloud Endpoints (Gemini / MiniMax)
  ➔ Local CDP connection (Flow, zero extensions)

CLI Reference

Structured Terminal Commands

gflow image <prompt>

Generate images via Gemini Imagen 3 (default, extension-free) or Google Flow Imagen 4.

Flags: -P, --provider [gemini|flow] · -a, --aspect · -c, --count · -o, --output
gflow video <prompt>

Generate videos via Gemini Veo (default), MiniMax H3, or Google Flow.

Flags: -P, --provider [gemini|minimax|flow] · -d, --duration · -r, --resolution · -o, --output
gflow audio <prompt>

Generate background music and audio tracks using Gemini's Lyria / MusicFX pipeline.

Example: gflow audio "upbeat acoustic guitar with light percussion"
gflow chat <prompt>

Direct conversational chat in your terminal with Gemini Flash. Zero setup required.

Output: clean plaintext directly to stdout, ideal for pipes and shell scripts.
gflow status

Probe and inspect authentication and connection readiness across all three providers.

Flags: --json for automated tooling integrations and health checks.
gflow browser

Launches a dedicated Chrome instance with CDP enabled on port 9222 for Google Flow.

Opens flow.google.com; zero extensions needed.
